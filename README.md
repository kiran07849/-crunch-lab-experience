# Crunch/Lab — Lay's Crunch Experience concept

An original, responsive student portfolio concept inspired by the playful world of potato-chip flavours. It includes a cinematic hero, animated CSS snack packs, a flavour lineup, and an interactive **Crunch Lab** where visitors can combine up to three flavours, name their creation, reveal a custom box, and copy/share their mix.

## Run locally
No build tools or installation required.

1. Download and extract this folder.
2. Open `index.html` in a modern browser.
3. For best results, use VS Code with the Live Server extension.

## Publish with GitHub Pages
1. Create a new **public** repository in your own GitHub account.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site.
